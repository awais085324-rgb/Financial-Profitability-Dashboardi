# Executive Financial Performance & Profitability Dashboard | Power BI

This project presents an **interactive Power BI dashboard** designed to provide executive-level insights into financial performance, profitability trends, margin analysis, and discount impact.

The workflow started with **raw sample transactional data**, which was cleaned, transformed, and structured using **Power Query** before developing the final dashboard.

The objective of this project was to convert raw business data into **finance-driven business intelligence** to support data-backed strategic decision-making.

## Project Highlights

Monitored overall sales and profitability performance

Analyzed profit margin and discount effectiveness

Performed category-wise and segment-wise financial analysis

Identified most profitable and underperforming products

Built monthly and annual trend reporting

Delivered region and country-level revenue insights

Enabled interactive KPI monitoring through dynamic filters and slicers
